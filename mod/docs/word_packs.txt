todmod word packs
=================

A word pack is a folder in dict\ that replaces the words the game asks you to type.
Choose which packs are used, and in which order, in todmod_config.exe (Word packs).
The top pack wins; anything no pack provides comes from the game's own words. Tick "Mix the words of all
packs in use" ([dictionary] mix=1) to combine every pack's words for each list instead.
"Check coverage" in todmod_config.exe shows whether any word list would still use the game's own
(Japanese) words with your current packs.

A pack can describe itself: put a short text in description.txt (UTF-8) in the pack folder, and todmod_config.exe
shows it under the pack lists when the pack is selected.


Easiest: make a pack from your own word list
--------------------------------------------
1. Write a plain text file (UTF-8), one word or phrase per line, in any language:

       apple
       banana
       good morning
       Straße
       한국어<TAB>hangugeo

   - Lines starting with # are comments.
   - Letters with accents are typed with the plain key (é -> e, ü -> u, ß -> ss, ł -> l).
   - For other scripts, add a TAB and how it should be typed in Latin letters (romaji for Japanese kana works too).
   - Latin, Greek and Cyrillic lines up to 48 characters fit on screen (they use narrow text when needed);
     Japanese, Chinese or Korean lines up to 24 characters. Longer lines are skipped.
   - More words give more variety. Include short words (1-3 letters) too: the game's first lists use them.

2. In todmod_config.exe click "New pack from word list...", pick the file, then Save.
   The pack is named after the file and placed at the top of "In use".

The tool fills all 432 normal word lists (main game and Kids' Mode), giving each slot a word of about the
same difficulty as the original, so short words appear where the game expects short ones and long phrases
near the end. Quiz lists (a question plus answers) and special-mode lists cannot be made from a plain word list:
put a pack that has them, such as the English pack, below yours in "In use", or write them yourself (see below).


Typing Space Harrier words
--------------------------
If you own Typing Space Harrier, its word banks can become a pack:
    python tools\tsh_to_word_list.py "<Typing Space Harrier folder>\WORD" tsh_words.txt
then "New pack from word list..." with tsh_words.txt. The words keep their kana readings, so they are typed in
romaji like the game's own Japanese words.


Words in file order
-------------------
Tick "Top pack's lines in file order" ([dictionary] in_order=1) to type a text from start to finish, e.g. a play
or a film script: each new word the game picks from a word list is the next line of the top pack's sequence.txt
(one line per entry, word or word<TAB>reading, # for comments), or of its words.tsv when it has no sequence.txt.
"New pack from word list..." writes sequence.txt with the usable lines of your file in their original order (packs
made before todmod 0.20.0 don't have it: make the pack again). Lines longer than the screen (24 cells) are left
out, so split long sentences into shorter lines.
- Letters, numbers and the game's short-word slots are not affected: they come from tables built into the game,
  not from word lists. A word the game picks from a list that is shorter than 4 keys also stays as it is
  ([dictionary] in_order_min_length=4), so short slots keep short words.
- The position is saved in dict\<pack>\sequence_position.txt, so the next game continues where you stopped;
  delete that file to start again. After the last line it starts over.
- Points and difficulty come from each line as usual.

Scoring
-------
Points depend on a word's difficulty (about 4 per key; digits and symbols cost more) and on how fast you type
it. todmod computes the difficulty automatically with the same rule the original word lists use, so new words
score like the originals.

Spaces in a word are typed like any other key and count for its difficulty (2 each). Untick "Spaces must be
typed (pack words)" ([typing] type_spaces=0) to leave them out of what you type, while the word keeps the points it
would have with the spaces.


Pack files
----------
A pack folder can hold:

    words.tsv     all main-game word lists
    kids.tsv      all Kids' Mode word lists

Each line: list<TAB>difficulty<TAB>display<TAB>reading
    - list: the game's word list name, e.g. S000L010 (".bin" may be added, e.g. S000L010.bin).
    - difficulty: a number, or empty / auto to compute it.
    - reading: how it is typed; may be left out when it equals the display text.
    - Further columns (such as a romaji column) are ignored, and lines starting with # are comments.
This is the same layout as a hab_tool.py words-export, so an exported word bank TSV can be used directly.

A quiz list is a question followed by its answers; the question line uses difficulty 12 and reading "?":
    SE01L101	12	Which is a State in the US?	?
    SE01L101		Alabama
    ...

One file per word list also works and takes priority over the TSV files for that list: S000L010.txt in the pack
folder (Kids' Mode: kids\S000L010.txt), each line "word", "word<TAB>reading" or "difficulty<TAB>word<TAB>reading".


Words built into the game
-------------------------
Some words are not in any word list but inside Tod.exe. A pack can replace them with these list names in words.tsv:

    builtin_letters       25 single letters (small enemies)
    builtin_kana          40 single kana (small enemies; kana typing mode)
    builtin_short_words   89 short words, letters and kana (fast enemies)
    builtin_drill         28 drill keys in this order: F J, 1-9 0, then 16 symbols
    builtin_staff_stage   27 staff names (credits)
    builtin_staff_kanji   27 staff names (credits)
    builtin_staff_kana    24 staff names (credits)

A shorter list is repeated to fill the slots; extra words are not used. Difficulty is worked out from each
word. "Check coverage" in the configurator shows which built-in lists still use the game's words.

Capital letters
---------------
"Capital letters must match" (todmod.ini [typing] case_sensitive=1) makes pack words case-sensitive: a capital
needs Shift and a small letter must be typed without it, as written in the word's reading (or display). With
"Score capitals as harder" each capital adds 4 to the word's difficulty, so such words score more.

Keyboard
--------
Typed characters follow your Windows keyboard layout (US, UK, German...), so ' " : and other symbols are on
the keys printed on your keyboard. "Keyboard layout" in todmod_config.exe ([input] keyboard_layout) can
instead use US QWERTY, Dvorak, Colemak or Workman by key position whatever Windows is set to (for example a
Dvorak typist on a shared PC), or the game's own Japanese layout (japanese).

Backspace cancels the word you are typing, like Esc ("Backspace also cancels the word", [input]
backspace_cancels=1; on by default). Name entry still uses Backspace to delete a letter.


The English version's words
---------------------------
If you own the English Typing of the Dead, tools\english_to_pack.py (Python 3) turns its word\ folder into a pack
that covers every word list of the game, main game and Kids' Mode, including quizzes:

    python english_to_pack.py "The Typing of The Dead\word" "...\TODEX\dict\english"
